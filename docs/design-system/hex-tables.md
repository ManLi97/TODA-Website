## Color — Hex Reference

### Foundation — black + anthracite

| Token         | Hex       | Role                          |
|---------------|-----------|-------------------------------|
| `--bg`        | `#000000` | True black canvas             |
| `--surface-1` | `#121212` | Recessed (darkest anthracite) |
| `--surface-2` | `#141414` | Soft mid — default panel      |
| `--surface-3` | `#292929` | Elevated — cards              |
| `--surface-4` | `#333333` | Hover / very elevated         |
| `--border`    | `#383838` | Hairlines, dividers           |

### Text

| Token              | Hex       | Role                   |
|--------------------|-----------|------------------------|
| `--text-primary`   | `#FFFFFF` | Headings, primary data |
| `--text-secondary` | `#A3A3A3` | Labels, helper text    |
| `--text-tertiary`  | `#6B6B6B` | Metadata, fine print   |

### Gold — primary accent

| Token        | Hex       | Role                                               |
|--------------|-----------|----------------------------------------------------|
| `--gold-200` | `#FCE49B` | Light tint (hover on text)                         |
| `--gold-400` | `#E8B73D` | Bright accent                                      |
| `--gold-500` | `#C8941A` | Primary — numbers, hairlines, single-word emphasis |
| `--gold-600` | `#9C7314` | Pressed / deep accent                              |
| `--gold-800` | `#5C420A` | Rare deep tint                                     |
| `--on-gold`  | `#2B1E08` | Text on gold fill                                  |

### Purple — secondary accent

| Token          | Hex       | Role                               |
|----------------|-----------|------------------------------------|
| `--purple-200` | `#D9CBEF` | Light tint                         |
| `--purple-400` | `#CBB5EF` | Bright accent                      |
| `--purple-500` | `#BBA6E8` | Secondary — counter-melody to gold |
| `--purple-600` | `#9D88C9` | Pressed                            |
| `--on-purple`  | `#231A33` | Text on purple fill                |

### Label / categorical tints

| Token           | Hex       | Role                                |
|-----------------|-----------|-------------------------------------|
| `--label-blue`  | `#6B8CBE` | Neutral data, facts, in-progress    |
| `--label-green` | `#5FB082` | Positive outcome, proof, success    |
| `--label-red`   | `#B85450` | Problem, friction, status quo       |
| `--label-terra` | `#B57236` | Blocked, waiting, alternative state |
